# 0001. モノレポにする

- 状態: 採用
- 日付: 2026-08-29

## 背景

5言語（C# / Java / TypeScript / Python / Rust）の実装を1人で保守する。
言語ごとにリポジトリを分ける案と、1つのリポジトリにまとめる案があった。

## 決定

**1つのリポジトリに `rust/` `csharp/` `java/` `python/` を並べる。**
仕様 (`docs/spec/`) と共通テストベクタ (`spec/testdata/`) はリポジトリ直下に置き、
全言語がそれを参照する。

## 理由

- 仕様変更が全言語に波及するため、**1つのコミットで全言語を更新できる**ことが決定的に重要
- テストベクタを共有リポジトリに置くと、バージョンずれが起きた瞬間に
  「どの言語が正しいのか」が分からなくなる
- クロス言語の適合性テストが、submodule や外部取得なしにそのまま走る

## 結果として受け入れること

- 各言語のエコシステム慣習（`crates.io` からリポジトリ直下を期待する等）から外れる。
  各パッケージのメタデータで `repository` とサブディレクトリを明示して補う
- CI が全言語分のツールチェーンを用意する必要がある

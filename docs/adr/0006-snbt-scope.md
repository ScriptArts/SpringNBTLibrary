# 0006. SNBT はバイナリへ写せる範囲だけを扱う

- 状態: 採用
- 日付: 2026-08-29

## 背景

1.21.5 以降の SNBT は `[1, "a", {}]` のような**異種要素のリスト**を許す。
一方、バイナリ NBT の `TAG_List` は単一型しか表現できない。

## 決定

**異種リストをパースしたら `MALFORMED_DATA` を返す。**
SNBT の対応範囲は「バイナリ NBT へ損失なく写せる部分集合」とする。

その他の 1.21.5+ 拡張（16進・2進リテラル、桁区切り `_`、符号接尾辞、
拡張エスケープ、末尾カンマ、`bool()` / `uuid()`）は**すべて対応する**。
これらはバイナリへ写せるため。

## 理由

- 異種リストは Minecraft 側でコマンド引数として特別な正規化を受ける。
  その正規化を再現するのは**コマンドパーサの領域**であり、
  データ形式ライブラリの責務を超える
- 中途半端に受理して勝手な型へ丸めると、
  利用者が気づかないうちに意図と違うデータを書き込むことになる
- 受理しないと決めれば、挙動が全言語で一致することを保証しやすい

## 結果として受け入れること

- コマンド文字列をそのまま食わせる用途では使えない場合がある。
  その制約を [機能一覧](../features.md) と [ガイド02](../guide/02-snbt.md) に明記する

# 0006. SNBTはバイナリへ写せる範囲だけを扱う

- 状態: 採用
- 日付: 2026-08-29

## 背景

1.21.5以降のSNBTは`[1, "a", {}]`のような異種要素のリストを許す。
一方、バイナリNBTの`TAG_List`は単一型しか表現できない。

## 決定

**異種リストをパースしたら`MALFORMED_DATA`を返す。**
SNBTの対応範囲は「バイナリNBTへ損失なく写せる部分集合」とする。

その他の1.21.5+拡張（16進・2進リテラル、桁区切り`_`、符号接尾辞、拡張エスケープ（`\N{文字名}`を除く）、末尾カンマ、`bool()` / `uuid()`）は**すべて対応する**。
これらはバイナリへ写せるため。
`\N{文字名}`は、実装間でUnicode文字名の表が揃わないため対応せず、`UNSUPPORTED_FEATURE`を返す。

## 理由

- 異種リストはMinecraft側でコマンド引数として特別な正規化を受ける。
  その正規化を再現するのは**コマンドパーサの領域**であり、データ形式ライブラリの責務を超える
- 中途半端に受理して勝手な型へ丸めると、利用者が気づかないうちに意図と違うデータを書き込むことになる
- 受理しないと決めれば、挙動が全言語で一致することを保証しやすい

## 結果として受け入れること

- コマンド文字列をそのまま渡す用途では使えない場合がある。
  その制約を[機能一覧](../features.md)と[ガイド02](../guide/02-snbt.md)に明記する

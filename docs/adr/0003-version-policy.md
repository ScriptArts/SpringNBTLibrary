# 0003. 読みは寛容・書きは最新固定

- 状態: 採用
- 日付: 2026-08-29

## 背景

対象は Java版 26.2 (DataVersion 4903)。
過去バージョンのワールド改変はサポートしないと決めている。
その「サポートしない」の実装方法に幅があった。

## 決定

- **NBT レイヤ (レイヤ1) は完全にバージョン非依存**。DataVersion を一切見ない
- **読み込み**: DataVersion に依らず構造ベースで解釈する。
  `4903` 以外なら既定で警告コールバックを呼んで続行する（`Warn` / `Error` / `Ignore` を選べる）
- **書き込み**: 常に `DataVersion = 4903` を書く。
  元が `4903` 以外のチャンクを書き戻そうとしたら既定で `UNSUPPORTED_DATA_VERSION`。
  `allow_foreign_data_version = true` で明示的に許可できる

## 理由

- 読み込みを厳格にすると、**壊れたワールドの調査**という有力な用途が塞がれる。
  読むだけならデータを壊しようがない
- 書き込みを寛容にすると、古いワールドを黙って新形式で上書きし、
  **利用者が気づかないうちに壊す**。ここは既定で止めるべき
- 「バージョン変換（アップグレード）は行わない」ことを明示するため、
  許可フラグの名前を `allow_foreign_data_version` とし、
  「変換する」ではなく「異物をそのまま許す」意味であることを名前で示す

## 結果として受け入れること

- 古いワールドを新バージョンへ移行する用途には使えない。それは Minecraft 本体の仕事
- Minecraft の新バージョンが出るたび `TARGET_DATA_VERSION` の更新と検証が必要になる

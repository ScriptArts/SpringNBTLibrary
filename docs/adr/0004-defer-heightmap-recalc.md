# 0004. Heightmap と光源の再計算は v0.1.0 では行わない

- 状態: 採用
- 日付: 2026-08-29

## 背景

`set_block` でブロックを書き換えると、チャンクの `Heightmaps` と光源データが
実際の地形と食い違う。これを本ライブラリが再計算すべきかどうか。

## 決定

**v0.1.0 では再計算しない。** 既存の値はそのまま保持し、
代わりに無効化するAPIを提供する。

- `chunk.clear_heightmaps()` — `Heightmaps` を削除し、Minecraft に再計算させる
- `chunk.invalidate_lighting()` — `isLightOn` を `0` にする

## 理由

- `MOTION_BLOCKING` などの判定には
  **「どのブロックが移動を妨げるか」「どれが葉か」のブロック定義テーブル**が要る。
  これは全ブロック分のデータであり、バージョンごとに変わり、
  それ自体が本ライブラリと同規模の成果物になる
- 光源伝播の再計算はさらに重く、実装を誤ると見た目が壊れる
- Minecraft は読み込み時にこれらを再計算できる。
  **削除して任せるほうが、中途半端に計算するより安全**

## 結果として受け入れること

- ブロック改変後、そのままでは草の生成やモブスポーン判定が一時的にずれうる。
  この制約は [機能一覧](../features.md) と
  [ガイド05](../guide/05-blocks-and-biomes.md) に明記する
- v0.2.0 でブロック定義テーブルを導入する際に再検討する
